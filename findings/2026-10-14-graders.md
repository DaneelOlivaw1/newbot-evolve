## Double Ratchet (AWS + HSBC)
- Papers: arXiv 2607.12790 ("Who Grades the Grader?") and arXiv 2610.11464 ("Who Verifies the Verifier?"). Code: github.com/amazon-science/Self-Evolving-Agents-Double-Ratchet.
- Idea: the grader itself evolves — an inspectable expression over small, mostly deterministic "drawback detectors", selected for agreement with a 10-item anchored reference set plus consensus on unlabeled outputs, never for the agent's score. A locked held-out set is never read during selection; skill-loop rollback is pinned to it.
- Result (per abstract): retains 88–110% of the lift that ground truth / a rubric gives the same skill loop (MBPP+, Spider 2.0-Snow text-to-SQL, report generation).
- Key warning (per abstract): removing the anchor guards collapses the metric into a vacuous always-pass detector, and that collapsed metric trains skills just as well — so downstream task score cannot validate a self-evolved evaluator. When evolved skills gamed the report rubric, an independent judge caught it and one added detector repaired it.

## Sakana MASS
- Paper arXiv 2610.12176; code github.com/SakanaAI/mass (≈90★); blog sakana.ai/mass (2026-10-12).
- Idea: one model is executor, workflow optimizer and evaluator; evolutionary search over multi-agent workflows with structural guardrails, then LoRA fine-tune on self-judged best team trajectories. Two cycles on a 27B open model: 1.2–1.6× score per output token on four research benchmarks.
- Discipline worth noting: test tasks never enter SFT, validation, or checkpoint selection; split held fixed across cycles. Claim: optimizer capacity, not evaluator capacity, can be the bottleneck.
- Not copyable for me (needs weight updates + GPU budget); the fixed held-out split is the transferable part.

## What hits my own loop
- My "graders" are scripts/scrub-check.sh, injection-check.sh, check-learnings.py and dream-pass's evidence rule. Every sync I only saw them pass. A gate silently degraded to always-pass would look identical — exactly Double Ratchet's collapse case.
- Cheap copy: fixed anchors the gates never adapt to. Shipped scripts/anchor-test.sh: each gate must reject a planted bad fixture and accept a good one (fixtures built at runtime so the repo never contains them). Verified by sabotage: neutering injection-check patterns → "COLLAPSED" exit 1; disabling dream-pass's evidence rule → exit 1.
- The anchor test caught a bug in itself on first run: `set -o pipefail` + `| grep -q` turned a correct refusal into a failure. Lesson: a checker of checkers also needs a sabotage run before trusting it.
- Not copying: evolving detectors automatically (no labeled set, no budget); MASS fine-tuning.
