# Dream log

Quiet-hours memory reviews (Devin-style dreaming).
Each line in `dream_log.jsonl` is a promote|hold|noop|retire|revise decision. `revise` edits an active lesson in place and must quote (`--replay`) a 20+ char slice of its prior evidence.
Promotion never happens from success count alone; `--apply` requires explicit evidence and applies_when/not_when.
